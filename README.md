# GOLDEN GOOSE 24K 🥚

**순금 24K 황금알을 낳는 거위** — 쓰다듬고, 기다리고, 도감을 채우는 수집형 클리커.
클릭 카운터 하나와 **순도 999.9의 24K 순금알** 34종, 그리고 그걸 다 모으고 싶어지는 마음이 전부다.

치지직 후원과 연동되어 **1,000 치즈당 거위를 10번 쓰다듬어** 준다.

*by [goormigrm](https://github.com/goormigrm)*

**접속**: https://goormigrm.github.io/golden-goose/

## 게임 규칙

| 항목 | 규칙 |
|---|---|
| 쓰다듬기 | 거위를 클릭할 때마다 카운터 +1 |
| 즉석 산란 | 쓰다듬다 보면 그 자리에서 알을 하나 낳기도 한다 — **확률은 화면에 공개하지 않는다** (`CLICK_DROP_CHANCE`) |
| 정기 산란 | **3분마다** 알 1개. 창을 닫아둔 동안에도 시간이 흘러 쌓인 만큼 한꺼번에 지급 |
| 등급 | 일반 45% · 고급 26% · 희귀 17% · 영웅 8% · 전설 3% · 신화 1% |
| 같은 등급 안에서 | 모든 알이 동일 확률 (총 **34종**) |
| 저장 | localStorage 자동 저장. 새로고침·재부팅해도 유지 |
| 완주 시간 | 도감 34종 완성까지 **보통 26분, 90%가 50분 안** (아래 밸런스 참고) |

### 밸런스

사람이 실제로 유지 가능한 속도를 **초당 5.5회**로 잡고, 도감 34종 완성이
**보통 30분 / 대부분 1시간 안**에 끝나도록 확률을 맞췄다.

| | |
|---|---|
| 알 획득 속도 | 분당 약 20개 (쓰다듬기 산란 + 3분 타이머) |
| 30분간 쓰다듬기 | 약 9,900회 |
| 완성 시간 | 25% 18분 · **중앙값 26분** · 75% 37분 · 90% 50분 · 99% 84분 |

가장 희소한 신화는 **종당 0.33%**(3종 합계 1%)라 이게 완주 시간을 결정한다.
`CLICK_DROP_CHANCE`나 등급 weight를 건드리면 위 숫자가 통째로 바뀐다 —
[HANDOVER.md](HANDOVER.md)의 밸런스 절에 재계산 스크립트가 있다.

### 순금 24K 알

전체 34종 중 6종이 **순도 999.9의 24K 순금**이다. 등급이 오를수록 함유량이 커진다.

| 알 | 등급 | 순금 함유량 |
|---|---|---|
| 금박 입힌 알 | 고급 | 0.05 g (금박 0.12μm) |
| 24K 황금 알 | 희귀 | 18.75 g (다섯 돈) |
| 골드바 알 | 영웅 | 1 kg |
| 태양의 알 | 전설 | 8 kg (융해 상태) |
| 창세의 알 | 신화 | 100 kg (순도 1000.0) |
| 거위신의 알 | 신화 | 1 t (계량 불가) |

보유 순금 총량은 화면 가운데 **24K 스트립**과 [기록]에 실시간 표시된다.

### 이름표 — 이 알을 누가 뽑았는지

둥지의 알마다 **처음 뽑은 사람**이 이름표로 붙는다. 후원한 시청자가 자기 이름이 박힌 알을
방송 화면에서 계속 보게 하려는 장치다.

| 이름표 | 언제 |
|---|---|
| 🟢 **후원 ○○○** | 그 후원으로 굴러간 쓰다듬기에서 나온 알 |
| 🟡 **쓰다듬기** | 스트리머가 직접 눌러서 나온 알 |
| ⚪ **거위가 스스로** | 3분 타이머로 저절로 낳은 알 |

후원은 **후원자별로 묶어서** 대기열에 넣기 때문에, 여러 명이 동시에 쏴도 각자 몫의 쓰다듬기에서
나온 알에 정확히 그 사람 이름이 붙는다. 알을 누르면 상세 창에 *처음 뽑은 주인공*과
*마지막으로 뽑은 사람*이 함께 나오고, 획득 알림 카드에도 그 자리에서 이름표가 뜬다.

**신화·전설은 알을 눌렀을 때 뽑은 사람이 전부 나온다.** 상세 창에 *처음/마지막* 아래로
`뽑은 사람 전원`이 횟수와 함께 나열된다(`후원 순금러 ×3`). 도감 목록 자체는 훑어보는 곳이라
칸 그대로 두고, 자세한 내역은 눌렀을 때만 보여준다.
나머지 등급까지 전원을 남기면 후원자가 수백 명이 되어 세이브가 비대해지므로 상위 두 등급만 기록한다.

## 치지직 연동

### 규칙

| 항목 | 값 |
|---|---|
| 환산 | 후원 **1,000 치즈 = 쓰다듬기 10회** |
| 단위 | 1,000 치즈 단위로 내림 (2,500 치즈 → 20회, 900 치즈 → 0회) · 치지직 후원 단위는 '원'이 아니라 **치즈**다 |
| 상한 | 없음 |
| 영상 후원 | 인정 (`config.js`의 `ACCEPT_VIDEO_DONATION`으로 끌 수 있음) |
| 적용 방식 | 받은 횟수만큼 자동으로 쓰다듬어 준다. **그 쓰다듬기에도 즉석 산란 확률이 그대로 적용**된다 |
| 처리 순서 | 한 번에 한 건씩. 밴드 윗줄에 뜬 그 후원의 쓰다듬기만 그 시간 동안 소진되므로 화면과 숫자가 어긋나지 않는다 |
| 화면 노출 | 상단 후원 밴드에 **닉네임 + 메시지 + 누적 건수**만 띄운다. 누적 치즈와 누적 쓰다듬기 횟수는 수입이 추정되므로 어디에도 표시하지 않는다. 치즈 액수는 후원이 도착한 순간의 현재 줄에만 잠깐 뜬다 |
| 명예의 전당 | 밴드 오른쪽에 **가장 높은 쓰다듬기 / 가장 많은 금 획득** 1위 닉네임을 띄운다. **닉네임만** 띄우고 횟수·g은 적지 않는다 — 숫자를 함께 적으면 그 사람의 후원 금액이 그대로 역산된다 |

큰 후원이 들어오면 6초에 걸쳐 카운터가 쭉 올라가고, 그 사이 알이 우수수 나올 수 있다.

### 개발자가 할 일 (최초 1회)

이 게임은 **전용 치지직 앱과 전용 프록시 워커**를 쓴다. (아래는 이미 완료된 상태)

1. **앱 등록** — [치지직 개발자센터](https://developers.chzzk.naver.com)에서 애플리케이션 등록,
   로그인 리디렉션 URI = `https://goormigrm.github.io/golden-goose/`, 후원 조회 권한 포함
2. **프록시 배포** — `proxy/` 폴더에서

   ```bash
   npx wrangler deploy
   ```

   배포 후 Client ID/Secret을 워커 Secret으로 등록한다. **개행이 붙으면 `INVALID_CLIENT`가 나므로 `printf '%s'`를 쓴다.**

   ```bash
   printf '%s' '<Client Secret>' | npx wrangler secret put CHZZK_CLIENT_SECRET
   ```

3. **주소 심기** — `config.js`의 `PRESET_CLIENT_ID`, `PRESET_PROXY_URL`을 채우고 push
   → 현재 값: 앱 `afd9f0b7-…`, 워커 `https://golden-goose-proxy.1117tkdrms.workers.dev`

Client Secret은 **워커의 환경변수에만** 있고 이 저장소 어디에도 없다.

### 스트리머가 할 일 (클릭 2번)

1. 치지직에 로그인된 브라우저로 사이트에 접속
2. 오른쪽 위 **[치지직 로그인]** → 공식 치지직 페이지에서 **[동의]** → 자동 복귀
3. 상단 배지가 **🟢 후원 수신 중**이면 완료

이후엔 접속만 하면 자동 재연결된다. 토큰은 본인 브라우저(localStorage)에만 저장된다.

⚠ 후원은 **이 탭이 켜져 있는 동안만** 수신된다. 닫아둔 사이의 후원은 소급 반영되지 않는다.
(정기 산란 타이머는 닫아둬도 계속 흐른다 — 후원 환산만 실시간이다)

## 화면 원칙

1. **알을 얻어도 클릭이 끊기지 않는다.** 획득은 모달이 아니라 우하단 알림 카드로 뜨고 스스로 사라진다
   (`pointer-events:none`). 클리커에서 알림을 닫으러 마우스를 옮기는 건 그 자체로 스트레스라서다.
   모달은 둥지·도감의 알을 **사용자가 직접 눌렀을 때만** 연다.
2. **PC 우선, 탭 없음.** 기록·확률 / 거위 / 둥지·도감을 3단으로 펼쳐 한 화면에 다 보이게 한다.
3. **후원이 이 게임의 중심**이라 탭 안에 숨기지 않고 상단 밴드에 항상 띄운다.
4. **화면에 숨기는 것** — 즉석 산란 확률, 후원 누적 금액, 후원 누적 쓰다듬기 횟수,
   그리고 연동/개발자·테스트용 정보 일체. 후원 테스트 패널은 `Ctrl+Shift+D` 로만 열린다.
5. **후원 밴드는 두 줄이다.** 윗줄에 지금 처리 중인 후원 한 건(진행 막대 포함)과 `+N 대기`,
   아랫줄에 누적 건수와 최근 후원 내역. 한 건도 건너뛰지 않고, 밀리면 표시 시간이
   2.6초 → 1.1초까지 짧아진다. **화면에 뜬 후원과 올라가는 쓰다듬기 숫자가 항상 같은 건을 가리킨다.**
6. **알은 거위에서 실제로 나온다.** 꽁무니에서 톡 튀어나와 바닥에 튕기고 둥지 쪽으로 날아가며 사라진다.
   한꺼번에 여러 개면 높은 등급부터 최대 8개까지 그린다(획득 개수 자체는 제한 없음).
7. **PC에서는 페이지가 스크롤되지 않는다.** 상단바·후원 밴드는 늘 제자리에 있고 각 칸이 자기 안에서만
   스크롤된다 — 내용이 밴드 밑으로 들어가 가려지는 일이 없다. 1240px 이하에서는 밴드가 같이 흘러간다.
8. **알마다 누가 뽑았는지 이름표가 붙는다.** 아래 참고.

## 실행 · 배포

빌드 도구가 없다. `index.html`을 브라우저로 열면 그대로 돌아간다.

로컬에서 서버로 띄우려면(치지직 OAuth 테스트에 필요):

```bash
npx serve .
```

**GitHub Pages 배포** — Settings → Pages → Source를 `Deploy from a branch` → `main` / `/ (root)`.
빌드 단계가 없으므로 Actions 워크플로가 필요 없다. push하면 몇십 초 뒤 반영된다.

## 파일 구조

```
index.html                    화면 구조 + 거위/24K 각인 SVG
proxy/worker.js               치지직 CORS 프록시 (Cloudflare Worker)
styles.css                    전체 스타일 (다크 + 금색)
config.js                     Client ID / 프록시 주소 / 게임 상수 ← 규칙 조정은 여기
eggs.js                       알 34종 데이터 + 등급표 + 알 SVG 렌더러
chzzk.js                      치지직 OAuth → 세션 → 후원 구독
game.js                       게임 로직 (클릭·산란·도감·후원 환산·저장)
vendor/socket.io-2.5.0.slim.js  치지직 세션 서버는 Socket.IO 2.x만 지원 → 버전 고정
docs/공지글-모음.md            시청자 공지용 복붙 상자
HANDOVER.md                   인수인계 문서 (정본)
```

### 자주 바꿀 만한 값 (`config.js`)

```js
const CLICKS_PER_1000   = 10;        // 1,000 치즈당 쓰다듬기 횟수
const DONATION_UNIT     = 1000;      // 환산 단위(원)
const DROP_INTERVAL     = 3*60*1000; // 정기 산란 주기
const CLICK_DROP_CHANCE = …;         // 쓰다듬기 1회당 즉석 산란 확률 (화면 비공개 값)
```

알을 추가하려면 `eggs.js`의 `EGGS` 배열에 한 줄 넣으면 된다. `id`는 세이브 키라 바꾸지 말 것.

### ⚠ 파일을 고쳤으면 버전 쿼리를 올릴 것

빌드 도구가 없어 파일명에 해시가 붙지 않는다. `index.html`의 `?v=2`를 그대로 두면
이미 방문했던 브라우저가 옛 `config.js`·`game.js`를 계속 쓴다.
**CSS/JS를 수정할 때마다 `index.html`의 `?v=` 숫자를 함께 올린다.**

### 소리

효과음도 배경음도 **음원 파일을 쓰지 않고 WebAudio로 직접 합성**한다. 저작권 문제가 원천적으로 없고,
받아올 파일이 없으니 저장소가 가볍고 오프라인에서도 그대로 돈다.

- **효과음** — 클릭, 산란(등급이 높을수록 화음이 길어짐), 후원 도착
- **배경음 1 · 어쿠스틱** — 78 BPM, G장조 `G–D–Em–C` 를 통기타 핑거피킹처럼 뜯는 잔잔한 루프.
  뒤에 얇은 패드가 깔린다. 농가 아침 느낌.
- **배경음 2 · EDM** — 128 BPM, A단조 `Am–F–C–G`. 네 박 킥 + 오프비트 하이햇 + 굴러가는 베이스 +
  16분음표 리드. 긴장감 있고 신나는 쪽. 킥·박수·하이햇도 샘플이 아니라 만들어 낸 잡음이다.

목소리를 가리지 않도록 음량을 낮게 잡았다(어쿠스틱 0.075 / EDM 0.055).
오른쪽 위 **[🎵 배경음 N]** 을 누를 때마다 **1 → 2 → 끄기** 로 순환하고, **[🔊 효과음]** 은 따로 끈다.
선택은 저장된다. 브라우저 정책상 소리는 화면을 한 번 누른 뒤부터 나온다.

### 후원 테스트 (개발·운영용)

**`Ctrl` + `Shift` + `D`** 를 누르면 왼쪽 아래에 테스트 패널이 열린다. 평소에는 화면에 흔적이 없어
방송을 보는 사람은 알아챌 수 없다. 랜덤 1건 / 5건 / 15건, 닉네임·금액 지정 전송을 할 수 있고
실제 후원과 **완전히 같은 경로**로 처리된다. `Esc` 또는 같은 단축키로 닫는다.

브라우저 콘솔에서도 가능하다:

```js
__gg.state()       // 현재 상태
__gg.lay(5)        // 알 5개 즉시 낳기
__gg.test(10)      // 랜덤 후원 10건 몰아치기
__gg.donate(10000, '닉네임', '메시지') // 후원 1건 지정 (10,000 치즈)
```
